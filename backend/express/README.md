### Task Manager API

Project based on _Bun_, it provides API for _task management_ application.

### Pre Requisites

- A configured .env file (see .env.example).
- _Bun_ version _1.3.4_ or greater.

### Dependencies used by the project

1. **jsonwebtoken**.
2. **nodemailer**.
3. **validator**.
4. **bcryptjs**.
5. **mongoose**.
6. **mongodb**.
7. **express**.
8. **multer**.
9. **sharp**.

### Dev Dependencies used by the project

1. **supertest**.
2. **env-cmd**.
3. **nodemon**.
4. **jest**.

### scripts

1. `bun start` for running the application in production environment.

2. `bun dev` for running the application in development.

3. `bun test` for running the application tests.
